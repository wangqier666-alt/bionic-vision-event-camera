# 仿生视觉 × 具身智能：事件相机能否支撑空间理解？

> **研究汇报**：事件流重建图像与 RGB 图像的对比验证
> **团队**：我爱我家小组（黄天翔、刘鑫懿、王启儿、台文文、金霈道、邱陈曦）

## 项目背景

具身智能（Embodied AI）需要持续获取环境信息以完成空间理解——包括目标检测、深度估计、语义分割以及 3D 空间关系建立。传统 RGB 相机以固定帧率采集整幅图像，静态场景中存在大量冗余像素；而**事件相机（Event Camera）** 受生物视网膜启发，仅在亮度变化超过阈值时异步输出事件 `e = (x, y, t, p)`，具备低冗余、宽动态范围、高时间分辨率等优势。

本项目围绕一个核心研究问题展开：

> **事件相机能否代替 RGB 相机，为具身智能提供三维空间理解所需的信息？**

## 研究内容

| 模块 | 说明 |
|---|---|
| 事件相机原理 | 像素异步触发机制、与 RGB 整帧采集的对比、借鉴人眼的信息处理机制 |
| 事件视觉重建 | 从事件流（无绝对亮度）重建图像：事件窗口/张量表示 → UNet+Transformer → 强度图 |
| 对比实验 | 同一场景同一视角下，事件重建图像 vs RGB 图像在空间任务上的效果对比 |
| 重建方法 | E2VID（CVPR 2019）、E-3DGS（3DS 2025）、Aholo 重建管线 |
| 未来方向 | 遮挡恢复（Event-based Synthetic Aperture Imaging）、视觉麦克风、非视域成像等 |

## 文件说明

- `仿生视觉-事件相机具身智能.pptx` — 完整研究汇报演示文稿（11 页），含事件流重建与 RGB 图像对比验证的实验设计与结果。

## 关键结论

- 事件相机更接近生物视觉机制，可为长期感知降低采集、传输与存储负担。
- 事件重建图像在低光、高动态场景下具有更宽的适应范围。
- 若事件重建图像在相同场景与视角下可获得接近 RGB 的空间任务效果，则事件相机有潜力替代 RGB 相机支撑具身智能的空间理解。
